# 06.04 - KPI Data Dictionary

## Purpose

Defines how KPI metadata, measure definitions, and semantic objects are documented for governance, onboarding, and auditability.

The data dictionary is the documentation contract for this portfolio's production-style model.

---

## Why It Matters for This Portfolio

For executives and recruiters, the dictionary shows that KPI definitions are:

- Explicit
- Reproducible
- Governed
- Interpretable across teams

For senior analysts, it provides fast traceability from business metric to model logic.

---

## Dictionary Scope

The dictionary should cover:

- Measures
- Tables
- Columns
- Relationships
- Business descriptions and interpretation notes

---

## Alignment Rule

Dictionary entries must stay aligned with:

- Step 05 KPI definitions
- Step 06 semantic model objects
- Validation controls in `05_Validation`

If model logic changes, dictionary updates are mandatory.
